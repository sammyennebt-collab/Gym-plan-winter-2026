# Gym plan winter 2026

Phone home-screen gym plan for Sammy. Opening the site shows the current plan, phase 4 (RP hypertrophy, 6 days). Phase 3 (recomp) is one tap away at the top of the page.

https://sammyennebt-collab.github.io/Gym-plan-winter-2026/

Turn Pages on once before that link will load: **Settings → Pages → Build and deployment → Source: GitHub Actions**. Then re-run the latest "Deploy GitHub Pages" workflow. The address starts working after that run succeeds.

## Add to an iPhone

1. Open the link in Safari.
2. Tap the Share button, then **Add to Home Screen**.
3. Leave the name as Gym and tap **Add**.

The icon opens straight into phase 4, full screen, without the Safari toolbar.

## What is saved on the phone

Weights typed into a plan are stored in this browser (phase 4 under `sammy_p4_weights`, phase 3 under `sammy_p3_weights`). They stay put if you leave and come back. Phase 3 exercise checks and set dots work the same way they did before: they last for the session, and are cleared on a fresh load.

After the plan has been opened once, it can be opened again with no connection. The Barlow / IBM Plex type is loaded from Google Fonts when you are online; offline, the phone falls back to a system font. Exercises, sets, reps, and notes are in the saved pages.
